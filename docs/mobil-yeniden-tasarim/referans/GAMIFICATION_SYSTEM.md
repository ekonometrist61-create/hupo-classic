# GAMIFICATION & MOTIVATION SYSTEM

## 5 katman
1. **Immediate:** doğru/yanlış geri bildirim, mikro XP.
2. **Daily:** günlük hedef, seri, görev.
3. **Mastery:** konu ustalığı, tekrar kuyruğu, yanlışın düzeltilmesi.
4. **Identity:** level, 40 karakter, rozetler.
5. **Social:** Ay Ligi, arkadaş challenge, güvenli sıralama.

## Anti-overgamification
- XP ekranın ana akademik metriğinin yerine geçmez.
- Leaderboard düşük sırayı utandırmaz; “ilk 10'a X XP kaldı” gibi next-goal framing kullanır.
- Streak kaybı tehdit diliyle sunulmaz. Recovery/freeze mekanizması varsa etik ve ölçülü kullanılır.
- Push notification günlük baskı yaratmaz; çocuk için cap uygulanır.

## Ödül yoğunluğu
`normal doğru < combo < günlük hedef < konu tamamlandı < seviye < karakter/rarity unlock` şeklinde görsel yoğunluk artar.
